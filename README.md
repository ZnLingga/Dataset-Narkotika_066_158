## Deskripsi Dataset

Repository ini berisi kumpulan dataset dokumen putusan pengadilan tingkat pertama perkara **Pidana Khusus** dengan klasifikasi **Narkotika dan Psikotropika** yang diputus oleh **Pengadilan Negeri (PN) Palangkaraya** pada tahun **2025**. 

Dataset ini dikumpulkan dan dikelola sebagai bagian dari pemenuhan Ujian Tengah Semester (UTS) mata kuliah **Temu Kembali Informasi (Information Retrieval)** pada capaian **[SUBCPMK-2]**: *Memahami Metadata, Format Dokumen, dan Markup Language dalam Temu Kembali Informasi*. Seluruh dokumen bersumber dari portal terbuka Mahkamah Agung Republik Indonesia yang bersifat publik dan tidak terikat Hak atas Kekayaan Intelektual (HaKI), sehingga dapat dimanfaatkan secara bebas untuk keperluan penelitian akademik, ekstraksi informasi (*information extraction*), pengindeksan teks, maupun pengembangan sistem pencarian dokumen hukum (*Legal Information Retrieval*).
